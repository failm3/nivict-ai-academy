# Уровень 1 — Быстрый: 18 обзорных уроков

> **Это учебный маршрут.** F01–F16 завершены на вводном уровне и содержат оформленные конспекты; F17 изучается, F18 запланирован. Режим: одна мысль за сообщение, пример, короткая проверка. Без обязательного кода и установок.

## Цель уровня

- Понять главные компоненты ИИ-систем и зависимости между ними.
- Отличать простую автоматизацию, LLM-приложение, workflow и агента.
- Читать несложные архитектурные схемы и объяснять, почему система может ошибаться.
- Знать, какие технические компетенции предстоит развить для работы AI/Agent Engineer и создания собственной Agent Factory.

**Ориентир:** 8–12 часов концентрированного изучения, больше при подробных вопросах. Этот уровень — вводный, **он не является профессиональной квалификацией**.

## Логика зависимости

F01–F03 дают словарь → F04–F06 объясняют модель → F07–F09 показывают инструменты и данные → F10–F12 объясняют управление задачами → F13–F15 объясняют качество и контроль → F16–F18 собирают общую картину.

В каждой отдельной заметке: главная мысль, последовательность подтем, пример, рабочая компетенция, применение к Agent Factory, проверка понимания, типичная ошибка и темы «вернёмся позже».

## Итоговая проверка уровня

Без программирования объяснить архитектуру условной системы: запрос пользователя → приложение и LLM → доступные инструменты и данные → оркестратор/цикл → проверка результата → безопасное завершение. Выявить, что лучше оставить обычным кодом. Уметь объяснить эту схему сотруднику.

Вопросы без тестовой «оценки» — до ясного понимания. **Статус «освоено» выставляется только после обсуждения.**
