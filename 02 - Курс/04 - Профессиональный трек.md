# Профессиональный трек — от самоучки до кандидата на инженерную роль

## Возможные специализации

**AI Agent / Agentic AI Engineer:** инструменты, оркестраторы, состояние, LLM API, интеграции, тесты, надёжность.

**Applied AI / LLM Engineer:** продуктовые LLM-системы, RAG, обработка данных, evals, серверные API, продакшен.

**ML / LLM Research Engineer:** обучение и дообучение моделей, математика, оптимизация, датасеты и экспериментальная методология. Обычно требует заметно более глубоких математических и вычислительных знаний.

Не смешивать эти профессии: создание агентных приложений и обучение крупной LLM — разные инженерные направления с частично пересекающейся базой.

## Профиль обязательных инженерных навыков

Python + Git + Linux + HTTP/JSON/API + базы данных + отладка + тестирование + архитектурное мышление.

На этом фундаменте: LLM API, tool calling, MCP, retrieval, agent workflows, orchestration, observability, evaluation, security, deployment.

**Не считать курс профессионально завершённым без самостоятельного кодирования и защиты решения.**

## Портфолио из четырёх этапов

1. **Контролируемый инструментальный агент.** Читает задачу, вызывает разрешённые инструменты, сохраняет результаты; имеет лимиты и тесты.
2. **RAG-система с оценкой.** Индексация материалов, поиск, ссылки на источники, измерение релевантности и ошибок на тестовом наборе.
3. **Оркестратор с восстановлением.** Несколько типов задач, маршрутизация, состояние, checkpoint, retries, логи, бюджет и эскалация.
4. **Agent Factory (капстон).** По структурированному запросу создаёт конфигурацию нового агента, выдаёт список инструментов и разрешений, проводит автоматические тесты; запуск только после явного допуска человека.

Отдельный исследовательский мини-проект для модели: дообучить небольшую открытую модель **или** обучить крошечную учебную модель с нуля и измерить качество. Не путать с обучением коммерческой LLM большого масштаба.

## Что должно быть в каждом проекте

- Задача и границы.
- Архитектурная схема и обоснование альтернатив.
- Рабочий исходный код и воспроизводимый запуск.
- Автоматические проверки и тестовые кейсы.
- Логи/trace, известные ошибки и способы восстановления.
- Измеримые результаты: качество, задержка, стоимость, надёжность.
- Безопасность: права инструментов, работа с секретами и недоверенными данными.
- Короткая демонстрация и понятная документация для другого разработчика.

## Проверка профессиональной готовности

На незнакомой задаче смочь: уточнить требования → выбрать подход без необоснованного усложнения → реализовать прототип → доказать результат → выявить ограничения → объяснить улучшения и компромиссы.

Практический ориентир для сильного самоучки: несколько законченных проектов, разбор чужого кода, тестирование, регулярная техническая обратная связь; курс сам по себе не гарантирует трудоустройство. Вакансии регулярно перепроверять: названия ролей и стеки меняются.
