# F16. Приложение с LLM, дообучение и своя модель

> **Статус:** начат после F15; понимание F16 пока не проверено.

**Опора:** [[02 - Курс/Быстрый уровень/F15 - Безопасность и участие человека|предыдущий урок]]  
**Главная мысль:** Использовать готовую LLM, дообучить существующую и обучить новую с нуля — три разных инженерных проекта.

## Что разберём последовательно
1. Готовая LLM через API или локальный сервер.
2. Настройка с контекстом, RAG и инструментами.
3. Fine-tuning/дообучение существующих весов.
4. Обучение с нуля: данные, вычисления, эксперименты.

## Один конкретный пример
Нужен агент поддержки: сначала проверяем готовую модель с документами, а не строим фундаментальную LLM с нуля.

## Зачем это будущему инженеру
Отличать Applied AI Engineer от ML/LLM Research Engineer и не переоценивать опыт интеграции API.

## Зачем это для платформы создания агентов
Выбирать способ использования моделей, не смешивая создание агента с обучением сети.

## Короткая проверка понимания
Разнести примеры «подключить API», «дотренировать модель» и «обучить архитектуру с нуля» по трём сценариям.

## Типичная ошибка
Называть настройку промпта созданием собственной LLM.

## Вернёмся позже
Датасеты, Transformer, градиенты, LoRA, GPU и лицензирование моделей.

## Подтверждено в диалоге — начало F16

- На выбор архитектуры поддержки по документации «Сайт Жив» пользователь первоначально ответил «своя модель с нуля», затем уточнил **двухконтурную стратегию**: готовая LLM для задач и оптимизации сейчас, параллельно — исследования и развитие собственной LLM для команды, проектов и личных интересов. Мотивы: больший контроль над данными и собственной инфраструктурой, стратегическая независимость. Пользователь понимает, что обучение с нуля дорого и ресурсозатратно.
- Техническое уточнение: для ответа по проектной документации **необязательно обучать модель с нуля или записывать знания в веса**. Готовая (в том числе локально размещённая) LLM + RAG/внешняя память + инструменты может использовать актуальные документы. Fine-tuning меняет параметры существующей модели; обучение from scratch — отдельный крупный проект. Собственные серверы дают контроль над размещением, но не исключают взлом, ошибки настройки, внутренние угрозы и утечки; нужны реальные меры безопасности.
- Рекомендовано разделить краткосрочный прикладной проект и долгосрочные эксперименты с обучением моделей; решение о создании модели с нуля принимать на основании задач и результатов сравнения с адаптацией существующих моделей.
- Следующий вопрос: какой из трёх подходов нужен, если обновили тарифы в документации и агент должен сразу отвечать по новой цене, без ожидания переобучения.
