# F04. Как LLM получает запрос и выдаёт ответ

> **Статус:** запланировано. Это маршрут будущего диалога, **не освоенный конспект**.

**Опора:** [[02 - Курс/Быстрый уровень/F03 - Автоматизация, бот, workflow, LLM и агент|предыдущий урок]]  
**Главная мысль:** Модель обрабатывает предоставленный контекст и генерирует выход; приложение управляет запросом, вызовом модели и дальнейшими действиями.

## Что разберём последовательно
1. Вход, контекст, выход.
2. Инструкции и пользовательский запрос.
3. Интерфейс чата и программный вызов модели.
4. Где заканчивается генерация и начинается работа приложения.

## Один конкретный пример
Чат формулирует ответ о возврате товара; сервер отдельно получает сведения о заказе.

## Зачем это будущему инженеру
Различать пользовательский интерфейс, LLM API и бизнес-логику.

## Зачем это для платформы создания агентов
Понимать, какие обязанности передавать модели, а какие — исполнительной программе.

## Короткая проверка понимания
Нарисовать три блока: интерфейс → приложение → модель; отметить путь ответа.

## Типичная ошибка
Считать, что модель видит все файлы и базы данных сама по себе.

## Вернёмся позже
Параметры API, SDK, транспорт, streaming.
