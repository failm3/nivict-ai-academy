# Матрица компетенций

| Область | Быстрый | Обычный | Продвинутый |
|---|---|---|---|
| Фундамент | Объясняет компоненты | Пишет базовый код и читает API | Проектирует и отлаживает сервисы |
| LLM | Понимает генерацию и ограничения | Использует API и тестирует ответы | Разбирает обучение и оптимизацию |
| Интеграции | Отличает инструмент от модели | Реализует API, RAG и MCP | Проектирует надёжные контракты |
| Оркестрация | Видит поток работы | Собирает сценарий с состоянием | Строит устойчивые графы и очереди |
| Качество | Отличает отчёт от доказательства | Создаёт проверяемые тесты | Ведёт evals, tracing, security и SLO |
| Своя система | Рисует архитектуру | Создаёт прототип | Защищает и эксплуатирует платформу |

## Статусы

- **Не начинали** — материал ещё не разбирали.
- **Обсуждаем** — понятия ещё уточняются.
- **Понял** — ученик смог объяснить своими словами.
- **Применил** — есть проверенная практика.
- **Могу обучить** — провёл понятное объяснение другому человеку.

Никаких автоматически присвоенных достижений. Освоение подтверждается диалогом и результатами практики, где она предусмотрена.
