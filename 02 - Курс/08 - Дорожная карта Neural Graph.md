# NIVICT Neural Graph — развитие вместе с обучением

> Цель: граф **реальных освоенных знаний**, а не декоративная картинка, изображающая биологический мозг. Никаких постоянных правых панелей. Визуальный ориентир — плавное погружение от общей сети к выбранному узлу и к его связям.

## Основное правило роста

**Каждый завершённый и подтверждённый в диалоге урок:** оформляем конспект, записываем действительно освоенные понятия, создаём или обновляем смысловые связи Obsidian `[[...]]`. Граф читает структуру заметок и их метаданные, а не делает вывод об усвоении знаний по числу сообщений.

**Урок завершён** ≠ **понятие освоено**: отдельные понятия могут требовать повторения. Не приписывать пользователю освоенные знания без проверки. Не создавать несуществующие смысловые связи ради красоты.

Предлагаемые состояния содержимого:
- `planned` — будущая тема, едва заметный узел.
- `in-progress` — текущая тема, акцентированный контур.
- `understood` — понятие объяснено пользователем своими словами, мягкое свечение.
- `completed` — урок подтверждён, устойчивый яркий узел.
- `review` — требует повторения, без ложного статуса «освоено».

Статусы требуют явного подтверждения в диалоге и фиксируются в заметках; плагин не определяет понимание сам.

Нумерация версий — **план**, а не обещание автоматического релиза: начало этапа определяется успешным освоением соответствующего урока и готовностью реализации. Если функция не готова, урок не задерживать; переносить работу над плагином на отдельную сессию.

## Правило обновления после каждого урока

1. Проверить понимание через объяснение своими словами или небольшой пример.
2. Зафиксировать итог урока в GitHub/Obsidian; добавить только достоверные связи и при необходимости заметки понятий.
3. Обновить `02 - Курс/07 - Прогресс.md`.
4. Граф перечитывает изменившиеся заметки и визуально отражает новые связи/состояния **только если текущая версия плагина умеет их отображать**.
5. После уроков-триггеров отдельно улучшать сам плагин согласно таблице и тестировать на локальной копии.

### Важно: два независимых потока обновлений

- **Данные графа** = Markdown и ссылки курса. Они идут по пути ChatGPT → приватный GitHub → Obsidian Git (автополучение настроено на 5 минут; реальную работу автоматического интервала проверять отдельно).
- **Код Neural Graph** = локальный плагин в `.obsidian/plugins/nivict-neural-graph`. Папка `.obsidian/` исключена локально из Git. Следовательно, изменения в репозитории курса **не обновляют код плагина**. Для новых возможностей нужен отдельно проверенный пакет плагина и его локальная установка. Не заявлять, что обновление плагина произошло только потому, что изменился GitHub.
