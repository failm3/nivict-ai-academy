## Что действительно остаётся разрабатывать в AWE

Небольшие стыковочные контракты: Owner-signed/versioned requirements; actor/project/task/tool identity; policy enforcement before effect; budget reservation and bounded recursive lifecycle; evidence bindings to exact deployed artifact/config; immutable critical QA and separate examiner identity; memory ingest/ACL/TTL; external-effect idempotency/reconciliation; post-save readback and recovery state machine. Эти требования специфичны для AWE и не исчезают после установки framework.

Не требуется самостоятельно создавать browser automation engine, общий MCP protocol stack, OAuth implementation, GitHub/Workspace API clients, vector index, tracing system, generic model proxy, tokenizer или большой document parser. Доказательств количественной экономии человеко-часов/денег нет. Сначала один сопоставимый пилот на существующем Head, затем решение о дополнительных компонентах.
