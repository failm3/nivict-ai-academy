## Жизненный цикл

`candidate_to_study` → `in_review` → `validated` / `rejected` / `deferred` → `approved_for_use` → отдельная установка и тесты.

Правила: факт установки не следует из записи в каталоге; нельзя автоматически рекомендовать использовать непроверенный код или выдавать высокий confidence классификации за проверку безопасности. Статусы заносить с источником и результатом проверки. Для удаления кандидата нужна явная причина; лучше помечать `rejected`, сохраняя оригинал.

## Как перенести в Obsidian и GitHub

1. Скачать архив `NIVICT-Tools-4504-Candidates-Obsidian.zip` из чата ChatGPT.
2. В локальном клоне репозитория выполнить `04 - Инструменты/import-candidates.ps1` с параметром `-ArchivePath`, указывающим на скачанный ZIP.
3. Скрипт проверит SHA-256, предварительное состояние Git и 4 504 карточки, скопирует каталог в локальное хранилище, затем попробует сделать коммит и push.
4. Проверить `git status` и открыть каталог в Obsidian. Не запускать импорт повторно поверх существующей папки.
