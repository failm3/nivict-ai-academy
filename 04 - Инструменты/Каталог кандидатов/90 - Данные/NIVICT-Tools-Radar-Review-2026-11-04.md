## Начальный пакет проверок
1. **MCP Inspector:** на изолированной конфигурации вывести доступные инструменты, проверить права и ограниченные тестовые вызовы; не переносить секреты.
2. **Playwright MCP/CLI:** E2E на тестовом сайте по 320/390/768/1024/1440/1920 px, собрать скриншоты, ошибки консоли, сетевые ошибки и результаты тестов. Сравнить с уже используемым browser-harness.
3. **Chrome DevTools MCP:** проверить консоль, запросы, производительность и веб-ошибки на тестовом профиле, не на личном Chrome.
4. **Codebase Memory MCP:** проиндексировать безопасную копию проекта; сопоставить правильность поиска и стоимость контекста с существующей связкой.
5. **Security:** применить методику Cloudflare для обзора прав инструментов; оценить ToolHive/MCP-Scan только после проверки практических рисков и данных, уходящих наружу.
