## Исходное описание

> fyne-io/fyne — Кроссплатформенный UI-тулкит для Go, вдохновлённый Material Design. Позволяет создавать приложения для desktop и мобильных устройств из единой кодовой базы. Поддерживает Windows, macOS, Linux, iOS и Android. — Включает набор готовых виджетов и API для построения интерфейсов. Приложение запускается командой `go run` без дополнительной конфигурации.
