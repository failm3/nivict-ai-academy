## Исходное описание

> capcom6/android-sms-gateway — Приложение для Android, которое превращает смартфон в SMS-шлюз. Через REST API или CLI-инструмент можно отправлять и получать SMS из сторонних приложений и сервисов. Работает на Android 5.0 и выше, регистрация не требуется. — Поддерживает два режима работы: локальный сервер на устройстве и облачный сервер для случаев, когда прямой доступ к устройству невозможен.
