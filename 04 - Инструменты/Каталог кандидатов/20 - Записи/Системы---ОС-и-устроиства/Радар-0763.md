## Исходное описание

> jgraph/drawio-desktop — Десктопное приложение для создания диаграмм, построенное на базе Electron. Оборачивает редактор draw.io в автономную программу, которая работает без браузера. Доступно для Windows, macOS и Linux. На Windows есть три варианта установки: через NSIS-инсталлятор с правами администратора, через MSI без прав администратора и в виде портативной сборки без установки. — ❤
