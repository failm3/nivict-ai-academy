## Исходное описание

> permissionlesstech/bitchat — Bitchat — это уникальное приложение для общения через Bluetooth Mesh, создающее атмосферу IRC. Оно позволяет пользователям обмениваться сообщениями в оффлайн-режиме, используя сеть из множества устройств. Идеально подходит для ситуаций, когда интернет недоступен, или для создания локального чата на мероприятиях. — 🔥
