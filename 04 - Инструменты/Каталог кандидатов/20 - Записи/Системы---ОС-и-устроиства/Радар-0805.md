## Исходное описание

> ramensoftware/windhawk — Инструмент для кастомизации программ на Windows. Windhawk использует глобальный инжект и перехват функций (hooking) для изменения поведения запущенных приложений без изменения их исполняемых файлов. — Основа системы — моды: отдельные модули, которые подключаются к целевым процессам и меняют их работу. Для создания и управления модами используется расширение для VSCode со встроенным интерфейсом.
