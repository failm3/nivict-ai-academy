## Исходное описание

> swaywm/sway — Wayland-композитор с полной совместимостью с i3. Позволяет использовать существующий конфиг i3 без изменений — достаточно скопировать файл конфигурации, и он заработает сразу. — Можно развернуть локально. Запускается из TTY или через display manager. Поддерживает установку из пакетов большинства дистрибутивов Linux или сборку из исходников с помощью meson и ninja.
