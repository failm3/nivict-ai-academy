## Исходное описание

> boltgolt/howdy — Инструмент позволяет входить в Linux с помощью распознавания лица вместо пароля — как Windows Hello. Он встраивается в стандартную систему аутентификации PAM и работает везде, где обычно нужен пароль: вход в систему, экран блокировки, sudo. Для распознавания используется встроенная камера с инфракрасной подсветкой. Поддерживаются Debian, Ubuntu, Arch Linux, Fedora и openSUSE. — 👍
