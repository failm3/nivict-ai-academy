## Исходное описание

> 2dust/v2rayNG — Клиент для Android, который обеспечивает работу с протоколом V2Ray. Поддерживает два ядра: Xray core и v2fly core. Работает на Android начиная с версии 5.0 (Lollipop). — Приложение использует файлы геолокации geoip.dat и geosite.dat для маршрутизации трафика по IP-адресам и доменам. Поддерживает сторонние dat-файлы — их можно подключить вручную из той же папки.
