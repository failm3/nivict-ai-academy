## Исходное описание

> coreybutler/nvm-windows — Инструмент для управления несколькими версиями Node.js на Windows. Рекомендован Microsoft, npm и Google как официальный менеджер версий Node.js для этой платформы. Написан на Go и не является портом оригинального nvm, который работает только на macOS и Linux. — Позволяет устанавливать, переключать и удалять версии Node.js через командную строку. Поддерживает Node.js версии 4 и выше.
