## Исходное описание

> Moya/Moya — Сетевой уровень абстракции для iOS-приложений, написанный на Swift. Moya оборачивает Alamofire и скрывает работу с URL, параметрами и деталями запросов. Вместо самописных «APIManager» и «NetworkModel» разработчик получает единый структурированный слой для работы с сетью. — Ключевая особенность — описание эндпоинтов через enum. Это даёт проверку корректности обращений к API на этапе компиляции.
