## Исходное описание

> triggerdotdev/jsonhero-web — Веб-инструмент для просмотра и навигации по JSON-файлам. Поддерживает несколько режимов отображения: Column View, Tree View, Editor View. Column View вдохновлён macOS Finder и позволяет перемещаться по структуре с помощью клавиатуры, удерживать выбранный элемент при переходе к родительскому узлу и сравнивать значения одного пути в разных элементах массива. — ❤
