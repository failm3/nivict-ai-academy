## Исходное описание

> safing/portmaster — Бесплатный application firewall с открытым исходным кодом для Windows и Linux. Перехватывает сетевые пакеты на уровне ядра — через WFP на Windows и nfqueue на Linux. Определяет, какое именно приложение установило соединение, в том числе для Snap, AppImage, скриптов, приложений Windows Store и системных служб вроде svchost.exe. — 👍
