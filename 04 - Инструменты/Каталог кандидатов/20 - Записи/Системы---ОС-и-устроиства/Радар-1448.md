## Исходное описание

> Ackites/Nrfr — Инструмент для изменения кода страны SIM-карты без рутирования устройства. Позволяет решать проблемы совместимости при международном роуминге, улучшая локализацию для пользователей зарубежных SIM-карт. С помощью этого решения можно обойти ограничения операторов и преодолеть региональные барьеры. Проект предоставляет необходимые функции для оптимизации работы с SIM-картами за границей. — ❤
