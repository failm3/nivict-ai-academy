## Исходное описание

> apache/hive — Инструмент для работы с большими наборами данных в распределённых хранилищах через SQL. Работает поверх Apache Hadoop и позволяет выполнять задачи ETL, формировать отчёты и проводить анализ данных без написания кода на MapReduce. Поддерживает чтение и запись данных из Apache HDFS и Apache HBase. — ⚡
