## Исходное описание

> blackcandy-org/blackcandy — Self-hosted сервер для стриминга музыки. Разворачивается локально через Docker одной командой — без сложной настройки. По умолчанию использует SQLite, но поддерживает PostgreSQL, если нужна более производительная база данных. — Медиафайлы подключаются через монтирование директории с хоста в контейнер. Есть мобильные приложения для Android и iOS, доступные в магазинах приложений.
