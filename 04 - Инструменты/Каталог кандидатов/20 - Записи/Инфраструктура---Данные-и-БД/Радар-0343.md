## Исходное описание

> amir20/dozzle — Веб-инструмент для просмотра логов контейнеров в реальном времени. Поддерживает Docker, Docker Swarm и Kubernetes. Не хранит лог-файлы — работает только с живым потоком данных. — Можно развернуть локально как Docker-контейнер весом 7 МБ. Из ключевых возможностей: нечёткий поиск по именам контейнеров, поиск по регулярным выражениям и SQL-запросам, разделённый экран для одновременного просмотра нескольких логов, живая статистика по CPU и памяти.
