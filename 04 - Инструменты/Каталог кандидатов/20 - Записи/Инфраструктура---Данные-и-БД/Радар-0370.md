## Исходное описание

> dubinc/dub — Платформа для управления короткими ссылками, отслеживания конверсий и партнёрских программ. Обрабатывает более 100 миллионов кликов и 2 миллионов ссылок в месяц. Можно развернуть локально для полного контроля над данными. — Построена на Next.js, TypeScript и Prisma. Для аналитики используется Tinybird, для кэширования — Upstash, для базы данных — PlanetScale. Поддерживает SAML/SSO через BoxyHQ.
