> akdeb/ElatoAI — ElatoAI предлагает решение для создания голосовых интерфейсов на базе Arduino ESP32, используя OpenAI Realtime API и Gemini Live API. Идеально подходит для разработки AI-игрушек, компаньонов и умных устройств.
