## Исходное описание

> fufankeji/deepseek-harness-studio — Десктопное приложение для расширения возможностей DeepSeek Harness без написания кода. Работает на Windows x64 и macOS arm64, разворачивается в один клик. Включает встроенный магазин плагинов: поиск, просмотр, установка, включение, отключение и удаление — без командной строки. — Перед установкой плагина показывает версию, разрешения, совместимость и уровень риска.
