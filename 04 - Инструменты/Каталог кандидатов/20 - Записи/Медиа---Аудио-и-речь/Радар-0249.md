## Исходное описание

> libredb/libredb-studio — Веб-инструмент для работы с базами данных, который разворачивается рядом с данными — в контейнере Docker или через npm — без необходимости открывать внешний доступ к серверу. Поддерживает PostgreSQL, MySQL, MongoDB, Redis, ClickHouse, SQLite и ещё десяток систем через единый интерфейс. Включает ER-диаграммы, сравнение схем, единый вход через SSO и запросы с помощью ИИ. — 👍
