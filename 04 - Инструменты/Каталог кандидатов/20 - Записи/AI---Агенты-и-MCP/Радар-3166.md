## Исходное описание

> yjid/kensakuЛокальный поисковик файлов для Windows, macOS и Linux на Rust. Ищет не только по названиям, но и внутри PDF, документов, исходного кода и скриншотов с помощью OCR. Поддерживает смысловой поиск, опечатки и запросы по датам. По данным разработчика, поиск по ста тысячам имён занимает около миллисекунды. Через MCP доступен агентам Claude и Cursor. Данные не отправляются в облако.
