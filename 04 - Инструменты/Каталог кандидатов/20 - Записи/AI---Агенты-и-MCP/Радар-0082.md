## Исходное описание

> cskwork/scopeweaver — Инструмент позволяет проводить автономное тестирование на проникновение с помощью нескольких языковых моделей одновременно. Серверная часть написана на Go, интерфейс — на Next.js. Поддерживается синхронизация активов из ScopeSentry: после указания адреса и ключа API данные автоматически попадают в граф активов для анализа агентами. Интерфейс доступен на английском и корейском языках. — 👍
