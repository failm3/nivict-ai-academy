## Исходное описание

> GongRzhe/Office-Word-MCP-Server — Сервер Model Context Protocol (MCP) позволяет создавать, читать и редактировать документы Microsoft Word. Он обеспечивает стандартный интерфейс для взаимодействия с документами, что упрощает работу искусственных интеллектов с текстами. Это решение идеально подходит для автоматизации обработки документов, интеграции с AI-ассистентами и улучшения функциональности текстовых редакторов. — 👍
