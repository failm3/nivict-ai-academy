## Исходное описание

> zhom/donutbrowser — Антидетект-браузер с поддержкой неограниченного числа профилей. Каждый профиль полностью изолирован: свой fingerprint, куки, расширения, прокси и DNS-блокировщик рекламы. Движки на выбор — Chromium (через Wayfern) или Firefox (через Camoufox), оба со спуфингом отпечатков. — Есть REST API и поддержка Model Context Protocol, что позволяет подключать автоматизацию и инструменты вроде Claude.
