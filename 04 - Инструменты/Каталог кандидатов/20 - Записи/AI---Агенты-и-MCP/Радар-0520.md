## Исходное описание

> autobrr/netronome — Инструмент для мониторинга производительности сети с поддержкой распределённых агентов. Можно развернуть локально — фронтенд и бэкенд упакованы в один бинарный файл размером с минимальным потреблением памяти около 35 МБ. Поддерживает Docker и запускается без сложной настройки. — Проводит тесты скорости через несколько провайдеров: Speedtest.net, iperf3 и LibreSpeed.
