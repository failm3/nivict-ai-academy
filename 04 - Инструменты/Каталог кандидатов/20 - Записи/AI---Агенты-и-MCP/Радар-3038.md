## Исходное описание

> IBM/mcp-context-forge — MCP Context Forge — это мощный шлюз и реестр для протокола контекста модели (MCP), который обеспечивает централизованное управление инструментами, ресурсами и подсказками для приложений, совместимых с LLM. Он преобразует REST API в MCP, создает виртуальные MCP-серверы с повышенной безопасностью и наблюдаемостью, а также осуществляет конвертацию между различными протоколами, такими как stdio, SSE и Streamable HTTP.
