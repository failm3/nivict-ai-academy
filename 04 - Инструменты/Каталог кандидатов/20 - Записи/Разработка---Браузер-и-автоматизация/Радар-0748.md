## Исходное описание

> puppeteer/puppeteer — JavaScript-библиотека для управления браузерами Chrome и Firefox через протоколы DevTools Protocol и WebDriver BiDi. По умолчанию запускает браузер в headless-режиме — без графического интерфейса. Устанавливается через npm и при установке автоматически загружает совместимую версию Chrome. — 👍
