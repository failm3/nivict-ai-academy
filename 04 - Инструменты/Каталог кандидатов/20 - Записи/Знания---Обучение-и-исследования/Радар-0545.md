## Исходное описание

> peterjthomson/marktext — Редактор Markdown с режимом живого предпросмотра (WYSIWYG). Работает на Linux, macOS и Windows. Поддерживает CommonMark, GitHub Flavored Markdown и частично Pandoc markdown. Из расширений доступны математические формулы через KaTeX, front matter и эмодзи. — Есть несколько режимов редактирования: Source Code, Typewriter и Focus.
