## Исходное описание

> xournalpp/xournalpp — Приложение для рукописных заметок с поддержкой аннотирования PDF. Работает на Linux, macOS и Windows 10, написано на C++ с использованием GTK3. Поддерживает планшеты с чувствительностью к давлению пера: Wacom, Huion, XP Pen и другие устройства. — Позволяет делать заметки поверх PDF, выделять и подчёркивать текст из документа, переходить по ссылкам внутри него.
