## Исходное описание

> diegomura/react-pdf — Библиотека для создания PDF-файлов с помощью React. Работает как в браузере, так и на сервере — в Node.js. Разработчик описывает структуру документа через компоненты: `Document`, `Page`, `Text`, `View`. Стили задаются через `StyleSheet.create` по аналогии с React Native. — В браузере PDF можно отобразить прямо в DOM через компонент `PDFViewer`.
