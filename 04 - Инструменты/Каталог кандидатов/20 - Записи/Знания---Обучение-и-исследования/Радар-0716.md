## Исходное описание

> marktext/marktext — Редактор Markdown с режимом реального времени WYSIWYG. Отображает результат форматирования сразу при вводе, без переключения между режимами редактирования и предпросмотра. Работает на Linux, macOS и Windows. — Поддерживает CommonMark, GitHub Flavored Markdown и частично Pandoc markdown. Из расширений доступны математические выражения через KaTeX, front matter и эмодзи.
