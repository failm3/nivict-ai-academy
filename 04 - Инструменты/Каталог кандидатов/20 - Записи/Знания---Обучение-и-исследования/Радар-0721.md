## Исходное описание

> ocrmypdf/OCRmyPDF — Утилита командной строки для добавления текстового слоя OCR в отсканированные PDF-файлы. После обработки документ становится доступен для поиска и копирования текста. Использует движок Tesseract и поддерживает более 100 языков, включая многоязычные документы в одном файле. — По умолчанию создаёт файлы в формате PDF/A, предназначенном для долгосрочного хранения.
