## Исходное описание

> is-a-dev/register — Бесплатный сервис для получения персонального поддомена в зоне `.is-a.dev`. Предназначен для разработчиков, которые хотят разместить личный сайт на читаемом адресе вида `username.is-a.dev`. — Чтобы получить поддомен, нужно сделать fork репозитория и открыть pull request по инструкции из документации. После проверки и слияния PR DNS-записи публикуются в течение нескольких минут.
