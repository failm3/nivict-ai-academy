## Исходное описание

> AutomaApp/automa — Расширение для браузера, которое автоматизирует действия в браузере через визуальный редактор на основе блоков. Блоки соединяются между собой и образуют рабочий процесс — без написания кода. — Поддерживает автозаполнение форм, выполнение повторяющихся действий, создание скриншотов и сбор данных со страниц. Можно задать расписание запуска автоматизации.
