## Исходное описание

> toeverything/blocksuite — BlockSuite представляет собой набор инструментов для создания веб-редакторов и совместных приложений. Он упрощает процесс разработки, позволяя разработчикам легко интегрировать функции редактирования контента и совместной работы. С помощью BlockSuite можно быстро настраивать редакторы под конкретные задачи, обеспечивая пользователям интуитивно понятный интерфейс для работы с данными.
