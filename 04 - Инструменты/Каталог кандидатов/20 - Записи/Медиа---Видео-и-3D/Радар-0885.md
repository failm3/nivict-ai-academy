## Исходное описание

> Immediate-Mode-UI/Nuklear — Минималистичная GUI-библиотека для C, умещающаяся в одном заголовочном файле. Никаких зависимостей, никакого рендер-бэкенда по умолчанию — только логика интерфейса и команды отрисовки примитивов, которые приложение выполняет само. — Работает в режиме immediate mode: интерфейс описывается прямо в коде на каждом кадре, без хранения состояния виджетов.
