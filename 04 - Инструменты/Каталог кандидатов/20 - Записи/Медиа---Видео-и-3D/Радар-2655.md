## Исходное описание

> huangxd-/danmu_api — Это лёгкий серверный API для получения и отображения “данмэ” (плавающих комментариев) из популярных китайских видеоплатформ вроде Bilibili и iQiyi. Репозиторий позволяет агрегировать комментарии в реальном времени без локального хранения данных. Поддерживает развертывание на Vercel, Cloudflare Workers и через Docker. Подходит для создания собственных видеоплееров с эффектом «летящих комментариев» или интеграции систем обратной связи в видео-сервисы. — ⚡
