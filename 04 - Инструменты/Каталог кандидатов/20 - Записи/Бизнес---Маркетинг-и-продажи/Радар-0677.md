## Исходное описание

> ClearURLs/Addon — Расширение для браузера на основе технологии WebExtensions. Автоматически удаляет параметры отслеживания из URL в фоновом режиме — без участия пользователя. Поддерживает Firefox и браузеры на основе Chromium. — Помимо очистки ссылок, блокирует распространённые рекламные домены, предотвращает hyperlink auditing (ping-трекинг), ETag-трекинг, отслеживание через History API.
