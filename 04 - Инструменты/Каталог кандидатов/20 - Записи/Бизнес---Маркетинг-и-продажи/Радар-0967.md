## Исходное описание

> Sylius/Sylius — Sylius — headless open-source платформа для eCommerce на PHP, построенная поверх Symfony и API Platform. Подходит, когда магазин и витрина разделены: фронтенд можно делать отдельным приложением, а бэкенд оставить как единый центр данных и бизнес-логики. — В основе — мощный REST API для интеграций с внешними сервисами и подключения разных клиентских интерфейсов: веб, мобильные приложения, терминалы.
