## Исходное описание

> LovesWorking/rn-better-dev-tools — Приложение для macOS, которое упрощает отладку React Query в любых приложениях на React — будь то мобильные, веб, ТВ или VR. С его помощью можно в реальном времени отслеживать запросы на разных устройствах через стильный интерфейс. Включает управление устройствами, визуализацию запросов, симуляцию состояния и автоматическую защиту в продакшене.
