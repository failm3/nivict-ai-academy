## Исходное описание

> hudikhq/hoodik — Self-hosted облачное хранилище с полным шифрованием данных на стороне браузера: сервер никогда не получает доступ к содержимому файлов. Поддерживает загрузку файлов, создание зашифрованных заметок и безопасный поиск по метаданным. Файлами можно делиться по ссылке — получатель расшифровывает их прямо в браузере. Разворачивается через Docker в одном контейнере. — ❤
