## Исходное описание

> cupcakearmy/cryptgeon — Инструмент для безопасной передачи заметок и файлов с автоматическим уничтожением после просмотра. Работает по принципу одноразовых ссылок: получатель открывает содержимое один раз, после чего данные удаляются. Можно задать ограничение по количеству просмотров или по времени. — Шифрование происходит на стороне клиента с помощью AES-GCM.
