## Исходное описание

> dutchcoders/transfer.sh — Инструмент для быстрой передачи файлов через командную строку. Файл загружается одной командой через curl и становится доступен по прямой ссылке. Поддерживается шифрование на стороне клиента через GPG и серверное шифрование AES256 через заголовок запроса. — При загрузке можно задать ограничение на количество скачиваний и срок хранения файла через HTTP-заголовки.
