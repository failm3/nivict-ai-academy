## Исходное описание

> streetwriters/notesnook — Приложение для создания и хранения заметок с полным сквозным шифрованием. Все данные шифруются на устройстве пользователя с помощью XChaCha20-Poly1305 и Argon2 — сервер не получает доступа к содержимому заметок. Работает по принципу zero knowledge. — Доступны клиенты для web, desktop (Electron) и мобильных платформ (Android, iOS через React Native).
