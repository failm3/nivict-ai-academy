## Исходное описание

> HotCakeX/Harden-Windows-Security — Инструмент для усиления защиты Windows исключительно штатными средствами операционной системы. Не использует сторонние компоненты и не расширяет поверхность атаки. Работает с актуальными сборками Windows и поддерживает сценарии для личного использования, корпоративного сегмента, государственных и военных структур. — Включает два основных приложения: Harden System Security и AppControl Manager.
