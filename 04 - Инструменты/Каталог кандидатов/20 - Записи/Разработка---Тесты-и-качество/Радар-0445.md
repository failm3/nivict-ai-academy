## Исходное описание

> go-gitea/gitea — Self-hosted платформа для организации разработки на основе Git. Включает хостинг репозиториев, code review, трекер задач, kanban-доски, wiki, реестр пакетов и встроенный CI/CD с поддержкой синтаксиса GitHub Actions. — Написана на Go, поэтому работает на Linux, macOS, FreeBSD, OpenBSD и Windows. Поддерживает архитектуры x86, amd64, ARM, RISC-V 64 и PowerPC.
