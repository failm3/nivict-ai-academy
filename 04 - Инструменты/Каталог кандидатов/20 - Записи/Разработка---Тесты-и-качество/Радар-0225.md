## Исходное описание

> Quick/Quick — Фреймворк для тестирования приложений на Swift и Objective-C, построенный на принципах BDD — разработки через описание поведения. Позволяет группировать тесты в читаемые блоки с описаниями сценариев и условий. В паре с ним используется Nimble — инструмент для написания понятных проверок результатов вместо стандартных утверждений. Поддерживает установку через CocoaPods и Swift Package Manager. — 🔥
