## Исходное описание

> trustedsec/ptf — Инструмент для пентестеров, которые хотят держать весь свой арсенал в актуальном состоянии на любой машине. PTF устанавливает, компилирует и обновляет коллекцию инструментов для тестирования на проникновение, организуя их по структуре PTES — стандарта выполнения пентестов. — Работает на Debian, Ubuntu и ArchLinux. Интерфейс напоминает Metasploit: те же команды use, show modules, update all.
