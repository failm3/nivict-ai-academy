## Исходное описание

> tirth8205/code-review-graph — Создание локального графа знаний для Claude Code позволяет эффективно управлять кодовой базой, обеспечивая её структурированный обзор. Это снижает количество токенов, необходимых для рецензирования кода, в 6,8 раз, а для повседневных задач — до 49 раз. Инструмент помогает сосредоточиться на важной информации, оптимизируя процесс работы с кодом и повышая продуктивность.
