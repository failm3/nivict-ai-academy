## Исходное описание

> frappe/builder — Визуальный конструктор сайтов с низким порогом входа, который можно развернуть локально в составе экосистемы Frappe. Позволяет собирать страницы в редакторе с интерфейсом, похожим на Figma, и публиковать их в один клик. Встроенная CMS на базе Frappe Framework даёт доступ к динамическим данным из базы без отдельного бэкенда. — ❤
