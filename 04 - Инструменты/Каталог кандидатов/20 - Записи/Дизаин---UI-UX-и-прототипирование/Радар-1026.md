## Исходное описание

> BabylonJS/Babylon.js — Babylon.js — движок для 3D‑рендеринга и игр в браузере на JavaScript. Он работает с canvas, собирает сцену из объектов, камер и источников света и выводит результат в реальном времени. — Подходит для интерактивной 3D‑графики: прототипов, демо, обучающих сцен и небольших экспериментов. Быстро попробовать API можно в Playground, где есть готовые примеры и шаблоны сцен.
