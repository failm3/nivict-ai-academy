## Исходное описание

> dunst-project/dunst — Лёгкий демон уведомлений для Linux с широкими возможностями настройки. Управляет отображением системных уведомлений: задаёт шрифты, иконки, тайм-ауты, цвета и горячие клавиши через конфигурационный файл. Можно развернуть локально без зависимости от конкретной desktop-среды. — Поддерживает правила: уведомления, соответствующие заданному шаблону, можно оформить иначе или изменить их поведение.
