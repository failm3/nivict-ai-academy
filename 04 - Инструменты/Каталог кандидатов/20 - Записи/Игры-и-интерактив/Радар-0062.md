## Исходное описание

> mattermost-community/focalboard — Инструмент для управления проектами, который можно развернуть локально. Он позволяет организовывать задачи в виде досок, карточек и таблиц, отслеживать прогресс и распределять работу между участниками команды. Доступны два варианта: настольное приложение для личных задач на macOS, Windows и Linux, а также серверная версия для совместной работы нескольких пользователей. — 👍
