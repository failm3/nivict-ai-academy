## Исходное описание

> CodeEditApp/CodeEditРедактор кода для macOS, созданный как нативное приложение без использования кроссплатформенных фреймворков. Поддерживает подсветку синтаксиса, автодополнение кода, поиск и замену по проекту, встроенный терминал и отладчик. Есть интеграция с git, инструменты для код-ревью и поддержка расширений. Интерфейс следует рекомендациям Apple по дизайну.
