## Исходное описание

> ratatui/ratatui — Rust-библиотека для создания текстовых пользовательских интерфейсов (TUI) в терминале. Подходит для командных утилит, дашбордов и других интерактивных консольных программ. — Предоставляет гибкий API для отрисовки виджетов и управления макетом. Поддерживает шаблоны проектов через cargo generate — можно быстро развернуть заготовку приложения без ручной настройки.
