## Исходное описание

> mrjackwills/oxker — Терминальный инструмент для управления Docker-контейнерами прямо из командной строки. Позволяет просматривать список контейнеров, запускать и останавливать их, читать логи и выполнять поиск по ним. Поддерживает сортировку контейнеров по столбцам и фильтрацию. Логи можно сохранять в файл. Инструмент можно развернуть локально или запустить через Docker. — ❤
