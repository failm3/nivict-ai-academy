## Исходное описание

> zsh-users/zsh-syntax-highlighting — Плагин для zsh, который подсвечивает команды прямо в процессе набора в интерактивном терминале. Подсветка работает до выполнения команды — это помогает замечать синтаксические ошибки до нажатия Enter. Требует zsh версии 4.3.11 и выше. — Плагин интегрируется через Zsh Line Editor (ZLE) и вычисляет подсветку для текущего содержимого командной строки при каждом изменении буфера.
