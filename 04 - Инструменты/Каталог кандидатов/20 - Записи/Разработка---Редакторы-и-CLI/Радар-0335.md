## Исходное описание

> usekaneo/kaneo — Инструмент для управления проектами с минималистичным интерфейсом. Kaneo позволяет командам отслеживать задачи и рабочие процессы без лишних функций и уведомлений. Проект распространяется под лицензией MIT и можно развернуть локально. — Поддерживает развёртывание через Docker Compose с PostgreSQL или через CLI-инструмент drim, который автоматически настраивает HTTPS, базу данных и все сервисы.
