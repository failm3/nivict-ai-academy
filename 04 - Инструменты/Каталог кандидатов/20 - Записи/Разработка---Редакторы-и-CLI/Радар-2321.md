## Исходное описание

> KolosalAI/kolosal-cli — kolosal-cli представляет собой легковесную альтернативу Ollama и Qwen Code для запуска крупных языковых моделей, таких как Llama 3.3, DeepSeek-R1, Phi-4, Gemma 3 и Mistral Small 3.1. Инструмент обеспечивает эффективное взаимодействие с моделями, упрощая их использование в различных приложениях. Он подходит для разработчиков, стремящихся интегрировать мощные языковые решения в свои проекты. — ❤
