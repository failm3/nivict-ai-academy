## Исходное описание

> charmbracelet/gum — Инструмент для создания интерактивных shell-скриптов с визуальным интерфейсом. Не требует написания кода на Go — все возможности библиотек Bubbles и Lip Gloss доступны напрямую из командной строки. — Предоставляет набор готовых команд: `choose` — выбор из списка вариантов, `input` — однострочный ввод с placeholder, `write` — многострочный ввод, `confirm` — запрос подтверждения.
