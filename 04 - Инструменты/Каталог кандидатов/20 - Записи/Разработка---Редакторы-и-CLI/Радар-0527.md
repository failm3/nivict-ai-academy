## Исходное описание

> yudai/gotty — Инструмент превращает любую CLI-команду в веб-приложение, доступное через браузер. Достаточно запустить gotty с нужной командой в качестве аргумента — например, `gotty top` — и терминал откроется по указанному адресу. По умолчанию сервер поднимается на порту 8080. — Можно развернуть локально.
