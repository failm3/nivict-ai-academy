## Исходное описание

> pyenv/pyenv — Инструмент для управления несколькими версиями Python на одной машине. Позволяет устанавливать любые версии Python и переключаться между ними на уровне системы, отдельного пользователя или конкретного проекта. Версию также можно задать через переменную окружения. — pyenv написан на чистом shell и не зависит от Python — проблемы с bootstrap нет.
