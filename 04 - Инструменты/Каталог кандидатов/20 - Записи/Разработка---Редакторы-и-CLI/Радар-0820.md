## Исходное описание

> abhixdd/ghgrab — Утилита для загрузки файлов и папок из репозиториев прямо из терминала, без полного клонирования. Работает с GitHub, GitLab, Codeberg, Gitea и Forgejo, включая self-hosted экземпляры. Написана на Rust с использованием tokio и ratatui. — Вместо `git clone` с последующим удалением лишнего — можно выбрать конкретные файлы или папки через TUI-интерфейс.
