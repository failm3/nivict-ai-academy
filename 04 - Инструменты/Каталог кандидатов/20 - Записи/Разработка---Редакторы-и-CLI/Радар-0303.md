## Исходное описание

> 89luca89/distrobox — Инструмент для запуска любого Linux-дистрибутива внутри терминала текущей системы. Использует Docker или Podman для создания контейнеров, при этом интегрирует их с хост-системой: контейнер получает доступ к домашней директории, устройствам, звуку, графике и X11/Wayland. — Позволяет запускать приложения из контейнера так, как если бы они были установлены на хосте, включая GUI-приложения.
