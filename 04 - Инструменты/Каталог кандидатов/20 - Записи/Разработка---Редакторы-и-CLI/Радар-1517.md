## Исходное описание

> jnsahaj/tweakcn — Редактор тем без кода для компонентов shadcn/ui, который позволяет пользователям легко настраивать визуальные элементы интерфейса без необходимости программирования. С помощью этого инструмента можно быстро изменять стили, цвета и макеты, что упрощает процесс создания уникальных дизайнов. Он подходит как для разработчиков, так и для дизайнеров, желающих ускорить работу над проектами.
