## Исходное описание

> jetify-com/devbox — Инструмент командной строки для создания изолированных окружений разработки. Разработчик описывает нужные пакеты в файле devbox.json, после чего devbox разворачивает окружение с точно указанными версиями инструментов. Все участники команды получают идентичную среду при запуске devbox shell. — Под капотом используется Nix — это даёт доступ к более чем 400 000 версий пакетов из Nix Package Registry.
