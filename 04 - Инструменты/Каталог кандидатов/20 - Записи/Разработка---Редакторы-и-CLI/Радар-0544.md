## Исходное описание

> chubin/wttr.in — Консольный сервис для получения прогноза погоды через HTTP-запросы. Работает без браузера: достаточно выполнить `curl wttr.in` в терминале. Определяет местоположение автоматически по IP-адресу, если не указан конкретный город. — Поддерживает несколько форматов вывода: ANSI-последовательности для терминала, HTML для браузеров, PNG для графических просмотрщиков.
