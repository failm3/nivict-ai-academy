## Исходное описание

> ntdevlabs/tiny11builder — Скрипт на PowerShell для создания облегчённого образа Windows 11. Автоматически удаляет встроенные компоненты и лишние пакеты, после чего собирает готовый загрузочный ISO-файл. Для создания образа использует только DISM и oscdimg.exe из Windows ADK — без сторонних утилит. Поддерживает любой выпуск Windows 11, любой язык и любую архитектуру. — В комплекте два скрипта.
