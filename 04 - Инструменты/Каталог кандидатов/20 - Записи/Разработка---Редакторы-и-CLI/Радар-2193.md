## Исходное описание

> coder/ghostty-web — Ghostty-web предоставляет веб-интерфейс для работы с терминалом, совместимый с API xterm.js. Он позволяет пользователям взаимодействовать с командной строкой прямо в браузере, обеспечивая удобный доступ к удалённым системам и приложениям. Это решение идеально подходит для разработчиков и системных администраторов, которым необходимо управлять серверами или выполнять команды без установки дополнительных программ.
