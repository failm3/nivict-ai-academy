## Исходное описание

> kimlimjustin/xplorer — Кроссплатформенный файловый менеджер для Windows, macOS и Linux, написанный на Rust и React с использованием Tauri 2. Поддерживает шесть режимов отображения файлов: Grid, List, Details, Column, Gallery и Tree. Работает с архивами ZIP, TAR, GZ, BZ2, XZ в том числе с парольной защитой. Файловые операции ускорены через memory-mapped I/O и параллельную передачу данных. — 👍
