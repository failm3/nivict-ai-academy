## Исходное описание

> mxrch/GHunt — Инструмент для OSINT-разведки по данным, связанным с аккаунтами Google. Принимает на вход адрес электронной почты, Gaia ID, ссылку на файл или папку Google Drive, а также BSSID — и возвращает информацию по каждому из этих объектов. Поддерживает геолокацию по BSSID и поиск связанных ресурсов через Digital Assets Links. — Работает через CLI с набором отдельных модулей.
