## Исходное описание

> dlvhdr/gh-dash — Инструмент работает прямо в терминале и позволяет управлять pull request'ами и задачами на GitHub без переключения в браузер. Можно настроить отдельные разделы для разных репозиториев, просматривать diff, оставлять комментарии и делать checkout. Управление полностью клавиатурное, с поддержкой vim-стиля. Все настройки задаются через YAML-файл, а действия можно адаптировать под свой рабочий процесс. — ❤
