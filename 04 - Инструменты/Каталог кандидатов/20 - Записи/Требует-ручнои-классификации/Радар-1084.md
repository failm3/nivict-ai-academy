## Исходное описание

> refined-github/refined-github — Это расширение для браузера, которое делает интерфейс GitHub более компактным и удобным для повседневной работы. Оно упрощает навигацию по страницам репозиториев, issues и pull request’ов, убирая лишний визуальный шум и добавляя небольшие улучшения в привычные места. — Подойдёт тем, кто много времени проводит в GitHub и хочет быстрее ориентироваться в списках, обсуждениях и деталях изменений.
