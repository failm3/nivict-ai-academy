## Исходное описание

> Gu1llaum-3/sshm — Утилита командной строки для управления SSH-подключениями с интерактивным TUI-интерфейсом. Написана на Go, распространяется как единый бинарный файл без зависимостей. Работает напрямую с существующим файлом `~/.ssh/config`, поддерживает директиву SSH Include и позволяет использовать произвольный конфигурационный файл через флаг `-c`. — 🔥
