## Исходное описание

> TryGhost/Ghost — Платформа для публикации контента, которую можно развернуть локально. Позволяет создавать блоги, медиаиздания и рассылки, а также управлять платными подписками и членством аудитории. Поддерживает создание собственных тем оформления и предоставляет API для интеграции со сторонними сервисами. Установка выполняется через командную строку с автоматической настройкой SSL. — ❤
