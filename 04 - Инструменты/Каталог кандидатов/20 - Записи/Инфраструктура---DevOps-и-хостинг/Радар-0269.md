## Исходное описание

> languagetool-org/languagetool — Инструмент для проверки грамматики, орфографии и стиля текста. Поддерживает более 25 языков, включая английский, немецкий, французский, испанский, польский и португальский. Находит ошибки, которые обычная проверка орфографии не обнаруживает. — Распространяется под лицензией LGPL 2.1. Можно развернуть локально как сервер с HTTP API, использовать из Java или запустить через Docker.
