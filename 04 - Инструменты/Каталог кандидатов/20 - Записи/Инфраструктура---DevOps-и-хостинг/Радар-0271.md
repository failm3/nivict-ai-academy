## Исходное описание

> overleaf/overleaf — Веб-редактор для совместной работы с документами в формате LaTeX. Несколько пользователей могут редактировать один документ одновременно в реальном времени прямо в браузере. — Можно развернуть локально через Docker. Платная версия Server Pro добавляет SSO через LDAP и SAML, отслеживание изменений и расширенные инструменты администрирования. Лицензия — GNU AGPL v3.
