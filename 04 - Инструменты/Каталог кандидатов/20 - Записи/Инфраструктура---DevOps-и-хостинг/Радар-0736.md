## Исходное описание

> librespeed/speedtest — Self-hosted инструмент для измерения скорости интернет-соединения. Работает без Flash, Java и WebSocket — только JavaScript, XMLHttpRequest и Web Workers. Измеряет скорость загрузки и отдачи, пинг, джиттер, определяет IP-адрес, провайдера и расстояние до сервера. — ❤
