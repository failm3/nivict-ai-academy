## Исходное описание

> gogs/gogs — Self-hosted Git-сервис, который разворачивается как единый бинарный файл без зависимостей. Работает на Linux, macOS, Windows и ARM-системах, включая Raspberry Pi. Написан на Go, потребляет мало памяти — для небольшой команды достаточно 2 ядер CPU и 512 МБ RAM. — Поддерживает доступ к репозиториям по SSH, HTTP и HTTPS.
