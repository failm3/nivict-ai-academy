## Исходное описание

> gitbucket/gitbucket — Self-hosted платформа для работы с Git-репозиториями, которую можно развернуть локально без сложной настройки. Поддерживает приватные и публичные репозитории, задачи, вики и уведомления по электронной почте. Совместима с GitHub API, что позволяет использовать привычные инструменты без изменений. Функциональность расширяется через плагины, а управление пользователями поддерживает интеграцию с LDAP. — ❤
