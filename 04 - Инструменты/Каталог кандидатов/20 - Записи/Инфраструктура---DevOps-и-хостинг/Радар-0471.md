## Исходное описание

> screego/server — Инструмент для демонстрации экрана с низкой задержкой и высоким качеством изображения. Разработан как дополнение к существующим решениям для связи, где качество трансляции экрана недостаточно для чтения кода. — Передача данных осуществляется через WebRTC. Поддерживается одновременная демонстрация экрана несколькими пользователями. Встроенный TURN-сервер обеспечивает работу через NAT.
