## Исходное описание

> kanbn/kan — Инструмент для управления проектами по принципу канбан-досок, аналогичный Trello, который можно развернуть локально через Docker. Позволяет создавать доски, приглашать участников рабочего пространства и управлять правами доступа. Поддерживает импорт досок из Trello, фильтрацию карточек по меткам, комментарии и журнал изменений. Для быстрого старта доступны готовые шаблоны досок. — 👍
