## Исходное описание

> traccar/traccar-web — Веб-интерфейс для платформы GPS-трекинга Traccar. Предназначен для работы с open source сервером Traccar, который поддерживает широкий спектр GPS-устройств. — Интерфейс построен на React, Material UI и MapLibre. Это фронтенд-часть платформы — для полноценной работы требуется отдельно развёрнутый бэкенд из основного репозитория Traccar. Платформу можно развернуть локально.
