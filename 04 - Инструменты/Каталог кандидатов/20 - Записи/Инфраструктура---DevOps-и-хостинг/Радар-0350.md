## Исходное описание

> HaschekSolutions/opentrashmail — Self-hosted решение для создания временных почтовых адресов. Включает собственный почтовый сервер на Python — не требует внешних SMTP-сервисов и работает с любым доменом без предварительной настройки адресов. Разворачивается через Docker. — Письма доступны через веб-интерфейс, JSON API, RSS-ленту и вебхуки. Поддерживает вложения, генерацию случайных адресов, удаление писем и аккаунтов.
