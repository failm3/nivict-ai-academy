## Исходное описание

> kubernetes/cloud-provider-gcp — Реализует интерфейс cloud provider для запуска Kubernetes-кластеров в Google Cloud Platform. Проект поддерживается командой Kubernetes в Google и включает несколько компонентов. — Cloud Controller Manager отвечает за управление зависимыми от облака контроллерами: состояние узлов, маршрутизация, балансировка нагрузки.
