## Исходное описание

> localsend/web — Веб-приложение для обмена файлами между устройствами через браузер без установки дополнительного программного обеспечения. Оно работает совместно с LocalSend и позволяет передавать файлы между браузерами и нативными версиями приложения. Проект можно развернуть локально с помощью Docker, включая собственный сигнальный сервер для полной независимости от внешней инфраструктуры. — 👍
