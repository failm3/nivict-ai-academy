## Исходное описание

> fastapi/full-stack-fastapi-template — Готовый шаблон для развёртывания full-stack веб-приложения. Включает FastAPI на бэкенде, React с TypeScript и Vite на фронтенде, PostgreSQL в качестве базы данных и SQLModel как ORM. Для стилизации используются Tailwind CSS и shadcn/ui. Фронтенд-клиент генерируется автоматически на основе API. — Шаблон можно развернуть локально или в продакшене через Docker Compose.
