## Исходное описание

> react-native-elements/react-native-elements — Набор готовых UI-компонентов для React Native. Работает на iOS, Android и в вебе — один и тот же код можно использовать в React Native и React-приложениях для браузера. Компоненты корректно отображаются на всех поддерживаемых платформах без дополнительных адаптаций. — Библиотека разделена на два пакета: `@rneui/base` содержит базовые компоненты, `@rneui/themed` добавляет поддержку тем оформления.
