## Исходное описание

> vercel-labs/scriptc — Инструмент позволяет превращать код на JavaScript и TypeScript в готовые программы, которые запускаются без установки Node.js. Все необходимые библиотеки включаются в один файл, поэтому программу можно передать другому человеку и запустить без дополнительной настройки. Поддерживает Windows, macOS и Linux, а также создание WebAssembly для запуска кода в других средах. — ❤
