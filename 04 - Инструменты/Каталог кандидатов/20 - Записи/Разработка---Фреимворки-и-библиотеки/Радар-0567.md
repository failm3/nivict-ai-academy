## Исходное описание

> auth0/Auth0.swift — SDK для интеграции аутентификации Auth0 в приложения на платформах Apple. Поддерживает iOS 14.0+, macOS 11.0+, tvOS 14.0+, watchOS 7.0+ и visionOS 1.0+. Требует Xcode 16.x и Swift 6.0+. — Включает несколько компонентов: Web Auth для входа через браузер, Credentials Manager для управления токенами, клиент Authentication API и клиент MFA API.
