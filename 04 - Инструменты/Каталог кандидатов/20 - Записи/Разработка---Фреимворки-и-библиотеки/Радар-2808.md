## Исходное описание

> ThioJoe/win-svg-thumbs-rust — Нативный обработчик миниатюр SVG для проводника Windows, разработанный на Rust с использованием только Windows API. Он позволяет отображать превью файлов SVG прямо в проводнике, упрощая их просмотр и управление. Благодаря эффективной реализации на Rust, приложение обеспечивает высокую производительность и надежность. Идеально подходит для пользователей, работающих с векторной графикой.
