## Исходное описание

> lasselian/prism-desktop — Десктопный клиент для Home Assistant под Windows и Linux. Работает через WebSocket API Home Assistant и отображает состояние устройств в реальном времени. Приложение сворачивается в системный трей и открывается по запросу, не занимая место на панели задач. — Позволяет управлять освещением, термостатами, вентиляторами, шторами, медиаплеерами, сенсорами, камерами, сценами и автоматизациями.
