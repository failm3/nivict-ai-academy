## Исходное описание

> NativeScript/NativeScript — Фреймворк с открытым исходным кодом для разработки нативных мобильных приложений на TypeScript. Даёт прямой доступ к нативным API iOS, Android и visionOS из JavaScript без промежуточного слоя. Приложение компилируется в нативный код, а не запускается в WebView. — Поддерживает работу с UIKit, SwiftUI, Android View и Jetpack Compose напрямую из TypeScript.
