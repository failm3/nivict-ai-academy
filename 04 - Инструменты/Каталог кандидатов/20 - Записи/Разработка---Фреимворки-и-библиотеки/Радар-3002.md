## Исходное описание

> google-deepmind/gemini-robotics-sdk — Gemini Robotics SDK — это мощный инструмент для разработки приложений в области робототехники. Он предоставляет удобные интерфейсы для управления различными типами роботов, включая мобильные платформы и манипуляторы. SDK включает в себя библиотеки для обработки сенсорных данных, планирования маршрутов и реализации алгоритмов машинного обучения.
