## Исходное описание

> n0-computer/iroh — Библиотека на Rust для установки соединений между устройствами по публичному ключу вместо IP-адреса. Приложение указывает, с каким узлом нужно соединиться, а iroh самостоятельно находит и поддерживает наиболее быстрый маршрут независимо от расположения устройства. — Для прямого соединения iroh применяет hole punching. Если это невозможно, соединение устанавливается через публичные relay-серверы.
