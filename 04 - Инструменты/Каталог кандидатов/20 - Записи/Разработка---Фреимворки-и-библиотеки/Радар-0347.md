## Исходное описание

> node-red/node-red — Визуальный инструмент для построения событийно-ориентированных приложений с минимальным количеством кода. Логика собирается из узлов на браузерном редакторе: узлы соединяются между собой, образуя потоки обработки данных. Можно развернуть локально через npm. — Поддерживает готовые узлы и пользовательские интеграции из библиотеки Node-RED Library.
