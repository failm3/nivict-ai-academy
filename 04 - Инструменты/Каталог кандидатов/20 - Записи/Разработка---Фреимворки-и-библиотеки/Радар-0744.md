## Исходное описание

> webtorrent/webtorrent — Торрент-клиент для node.js и браузера. Работает без плагинов и расширений — достаточно подключить JavaScript-файл на страницу. В браузере использует WebRTC для передачи данных между пирами по протоколу BitTorrent. В node.js работает через TCP и UDP как обычный торрент-клиент. — Поддерживает magnet-ссылки, обнаружение пиров через DHT, tracker, LSD и PEP.
