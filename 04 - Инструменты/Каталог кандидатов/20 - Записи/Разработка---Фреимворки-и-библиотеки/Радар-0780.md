## Исходное описание

> ionic-team/ionic-framework — Инструмент для разработки кроссплатформенных приложений на HTML, CSS и JavaScript. Из одной кодовой базы собираются нативные приложения для iOS и Android, а также Progressive Web Apps. — Основан на Web Components. Поддерживает Angular, React и Vue — каждый фреймворк доступен как отдельный пакет. Компоненты адаптируются под визуальный стиль целевой платформы автоматически.
