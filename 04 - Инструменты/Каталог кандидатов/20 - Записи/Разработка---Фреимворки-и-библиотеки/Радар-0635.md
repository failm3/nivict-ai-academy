## Исходное описание

> fastapi/sqlmodel — Библиотека для работы с SQL-базами данных из Python-кода через Python-объекты. Основана на аннотациях типов Python и использует Pydantic и SQLAlchemy в качестве основы. Устанавливается через pip одной командой. — Главная особенность — одна модель одновременно описывает и таблицу базы данных, и схему валидации данных. Не нужно писать отдельные модели для SQLAlchemy и Pydantic.
