## Исходное описание

> square/retrofit — Типобезопасный HTTP-клиент для Android и JVM. Позволяет описывать HTTP-запросы через Java- и Kotlin-интерфейсы с аннотациями — библиотека автоматически генерирует реализацию. Работает на Java 8+ и Android API 21+. — Использует OkHttp в качестве транспортного слоя. Доступен через Maven Central.
