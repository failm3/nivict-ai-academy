## Исходное описание

> gitextensions/gitextensions — Git Extensions — отдельное графическое приложение для работы с git-репозиториями в Windows. Подходит тем, кто предпочитает управлять ветками, коммитами и историей через интерфейс, а не через командную строку. — Инструмент встраивается в Windows Explorer и умеет открывать репозиторий прямо из проводника.
