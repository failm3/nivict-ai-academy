## Исходное описание

> Lymphatus/caesium-image-compressor — Инструмент для сжатия изображений с графическим интерфейсом. Поддерживает форматы JPG, PNG, WebP и TIFF. Позволяет уменьшить размер файла, сохраняя визуальное качество изображения. При необходимости можно одновременно снизить разрешение. — Работает на Windows 10 (сборка 1809 и новее), macOS 12+ и Linux. Для Windows доступны установщик и портативная версия, для macOS — DMG-пакет.
