## Исходное описание

> winapps-org/winapps — Инструмент позволяет запускать Windows-приложения, например Microsoft 365 и Adobe Creative Cloud, прямо в GNU/Linux рядом с обычными программами без видимых границ. Windows работает внутри виртуальной машины, а изображение передаётся через FreeRDP. Домашняя папка Linux доступна внутри Windows. Файлы можно открывать в нужном Windows-приложении через контекстное меню файлового менеджера. — ❤
