# AWE GROUP — независимая проверка выбора основы и CAREER-01

## 1. Сохранённый оригинал

Дословный Manus: [MANUS-FULL-PLATFORM-COMPARISON-CAREER01-2026-11-12.md](./MANUS-FULL-PLATFORM-COMPARISON-CAREER01-2026-11-12.md). Оригинальный отчёт не содержит результатов установки или живых испытаний.

## 2. Решение по архитектуре

Цель владельца неизменна:

Пользователь → Prompt Master (вопросы / согласование формального ТЗ) → **явный APPROVE** → Head (ресурсы, политика, бюджет, модели) → создаваемый под миссию менеджер → динамическое дерево вложенных исполнителей → независимый QA → доказанные артефакты, сохранение состояния и возврат пользователю.

Не подменять эту цепочку набором заранее названных профилей. Временные рабочие агенты и постоянные новые профили — разные механизмы и политики подтверждения. Не делать дизайн UI или буквальное расширение .exe более приоритетными, чем рабочий цикл.

## 3. Основа: реальная конкуренция

**Agent Zero**: рекурсивное делегирование и parallel есть в опубликованных исходниках/релизах; Windows A0 Launcher v1.9 реально публикует x64 EXE. `a0-create-agent` предназначен для сохранённых профилей и по умолчанию требует подтверждения перед записью. Нужны тесты настройки, временной специализации, модели/роли, параллелизма, QA и восстановления.

**Hermes Agent**: документированы `delegate_task`, `role=orchestrator`, `delegation.max_spawn_depth` (вложенность по настройке), независимые контексты, routing `model_map`/`profile_routes` через официальный плагин, рабочие деревья Git для параллельных кодовых задач. Desktop Windows существует в форме MSIX/AppInstaller — это Windows-приложение, а не технический дефект из-за отсутствия EXE. Однако наличие реально загружаемого актуального подписанного Windows-пакета следует проверять отдельно (есть жалоба о 404). У Hermes по документации crash незавершённого потомка → UNKNOWN; нет автоматической гарантии продолжения.

**OpenClaw**: документированы `sessions_spawn` и вложенные subagents с лимитами глубины, но безопасная конфигурация не «из коробки»; возможно использовать лишь после отдельной проверки политики.

**Eigent**: запасная desktop-альтернатива. **OpenHands**: специализированный coding-исполнитель позже. CAMEL/MAF/LangGraph/Agno/CrewAI/Dify/n8n — не добавлять как конкурирующих Head без доказанного разрыва.

**Вердикт:** выбор Agent Zero только по `.exe` преждевременен; Hermes обязан остаться равноправным претендентом до конкретного end-to-end теста. Не устанавливать несколько главных систем без предварительного выбора ограниченного пилота.

## 4. Первая миссия из GitHub проверена

- `AWE-CAREER-01 — первая реальная миссия агента.md` — 8 направлений.
- `CAREER-01 — ТЕКУЩИЙ ФОКУС И ПЕРЕХОД В НОВЫЙ ЧАТ — 2026-11-11.md` — сейчас 1) MARKET, 2) PORTFOLIO, 3) CV, строго последовательно. 4–8 на HOLD, никакие отклики, контакты и публикации без специального согласия.
- `CAREER-01 — MARKET — checkpoint — 2026-11-11.md` — 35 исторических URL, только 7 direct, 28 listings/snippets, неполный и не принятый рынок; нельзя объявлять вакансии актуальными на 12 ноября без перепроверки.

Рабочий первый вертикальный тест — **не синтетический CSV, а ограниченный настоящий MARKET-срез** через разрешённые поисковые API/источники, с датой, покрытием, вакансиями, дедупликацией, несколькими LLM маршрутами, структурой Head → manager → researcher(s) → independent QA. Первый тест не должен выдавать частичное покрытие за весь рынок.

По API hh.ru публичная документация описывает поиск, фильтры, `per_page <= 100`, глубину 2000 и возможную CAPTCHA без OAuth: https://api.hh.ru/openapi/redoc . Использовать законный доступ, не пытаться обходить ограничения или требовать сотни миллионов browser-LMM кликов.

## 5. Что Manus не доказал

1. Качественное выполнение реальной комплексной миссии, а не только наличие инструментов.
2. Автономную рекурсивную временную специализацию и выбор модели по стоимости/качеству на лету.
3. Технически обязательный APPROVE между Prompt Master и Head, невозможность неразрешённых внешних действий.
4. Независимую проверку по артефакту с отклонением специально испорченного результата.
5. Безопасное продолжение всего дерева после crash, общий hard budget, жёсткую OS-изоляцию.
6. Точные тарифы и cost per accepted result для конкретных профилей API-ключей.

## 6. Экономика

Router.Cheap, OpenRouter, официальный DeepSeek и локальный Ollama — кандидаты на **модельный слой**, не агентные платформы. Рекламные цены нельзя считать реальными издержками без учёта короткого/длинного контекста, cache, reasoning, tool fees, возвратов, ограничения ключа, фактической модели/качества и retries. Облачные LLM не становятся бесплатными из-за локальной оркестрации.

Из опубликованных тарифов Manus: пример 1 млн ввода + 0.2 млн вывода по short-tier Haiku 5.5 = $0.20 **только при полностью подходящем tier**; это не оценка бюджета AWE. Требуется провайдерный ledger на **всех** ролях и агентных деревьях, ограниченные spawns, concurrency, depth. На 32 ГБ RAM WSL и локальные программы практически возможны; GTX1650 не обосновывает обещания frontier-качества локальных LLM.

## 7. Самый короткий путь к рабочему результату

1. Зафиксировать одинаковую минимальную acceptance-проверку для 2 альтернатив, выбрать одну для изолированной проверки без замены старого OpenCode/AWE.
2. Подключить уже существующий инструмент поиска и разрешённый API; не интегрировать автоматически весь каталог 4504 кандидатов.
3. Проверить Prompt Master → ручное APPROVE → Head → временный project-agent → два агента/разные LLM → инструменты → artifact → QA → Git checkpoint.
4. Внести в журнал wall time, human time, total API paid usage, memory/CPU, failure reasons, число реальных вакансий и покрытые запросы.
5. STOP при техническом блокере или денежном лимите, не переходить на проектирование новых фреймворков по инерции.

**Действующая граница:** анализ выполнен; никакой новый runtime не установлен, платные API не вызывались, первая миссия не была запущена этим обзором. Требуется отдельное разрешение для установки/запуска/платных тестов.
