# AWE GROUP — актуальная передача (12 ноября 2026)

> **САМОЕ ГЛАВНОЕ ДЛЯ СЛЕДУЮЩЕГО ЧАТА:** пользователь хочет перестать разрабатывать агентный движок с нуля. Утверждён принцип **«готовая машина плюс тюнинг»**: один уже работающий open-source агентный продукт как основа AWE GROUP, дополнительные готовые интеграции/исполнители лишь по доказанной необходимости. **Никакую новую разработку не запускать до отдельного разрешения владельца.** Не выдавать перспективы за проверенную эксплуатацию.

## 1. Дословный отчёт Manus — новый важный источник

[MANUS-PRELIMINARY-ENGINEERING-ASSESSMENT-2026-11-12.md](./REPORTS/MANUS-PRELIMINARY-ENGINEERING-ASSESSMENT-2026-11-12.md)

- Manus отвечает **«частично»**: способен взяться за ограниченную рабочую систему с поэтапной приёмкой, но не гарантирует универсальную автономную цифровую организацию.
- Его **предварительная основа — Agent Zero** (Web UI, профили/подагенты, инструменты, память, локальный Linux runtime); **Eigent** — настоящая desktop-альтернатива при провале нужного параллелизма/UI; **OpenHands** — опциональный coding-исполнитель. Не смешивать конкурирующие оркестраторы.

- Предложены Web UI и A0 Launcher с Windows x64 EXE как готовая desktop-точка входа вместо разработки интерфейса с нуля; требует WSL/Docker и проверку установки.
- Оценка Manus: **240–480 инженерных часов** на ограниченную, проверяемую AWE (не гарантированная цена/срок), абсолютную стоимость в кредитах Manus **оценить достоверно отказался**. Никаких установок, тестов, платных LLM и репозиторных изменений по заявлению Manus не выполнялось.
- Это анализ **из документации**, а не результаты испытаний на пользовательском ПК. Цены/версии/лицензии в отчёте подлежат независимой проверке перед реальной разработкой.

## 2. Архитектура AWE — неизменная цель

**Миссия → Prompt Master → Head → оркестратор / PM → динамически сформированные специализированные агенты → оптимальный выбор модели и tools → реальное параллельное исполнение → независимая QA и ограниченные исправления → долговременная память / checkpoint / GitHub → пользовательский результат.**

Обязательные принципы:
- Универсальность: разработка, дизайн, маркетинг, исследования, браузер, работа с файлами и проектами; не только код.
- Исполнители могут выбирать/получать инструменты из каталога кандидатов (около 4 504 записей; **не равно работающим инструментам**), предпочтительно готовые MCP/Skills/API/CLI, с проверкой происхождения, прав и smoke-test.
- Сохранение истинного результата и состояния, защита от ошибочных повторов внешних действий, лимиты затрат, независимая проверка.
- **Не платить поминутно за внешние агентные sandbox-компьютеры** как обязательную часть архитектуры. Вычислительная нагрузка инструментов — собственный ASUS/WSL или впоследствии свой VPS/Mac. Облачные LLM через Router.Cheap допускаются и отдельно оплачиваются.
- Один главный управляющий контур, не три конкурирующих фреймворка и не новая самописная платформа до доказанной необходимости.
- Пользователь хочет **готовое Windows-приложение (EXE)** с чатами, проектами, рабочими процессами и мониторингом; переиспользование существующего интерфейса вместо пустой оболочки.
- **Локальная AWE должна работать независимо от Manus, Kortix и их платных тарифов.**

## 3. Текущее оборудование/инструменты

- Основной ноутбук: ASUS TUF F15, Intel i5-10300H, RAM 32 ГБ, GTX 1650, Windows + WSL2 Ubuntu.
- WSL: PostgreSQL 18.6, Node 22/24, Python, OpenCode 2.2.6, Ollama Qwen3 4B; локальные рабочие каталоги старой AWE. Конкретный текущий статус этих процессов в новом чате **не проверен**.
- Возможный второй компьютер: MacBook Pro M4 Pro, unified memory 24 ГБ, принадлежит коллеге. Не нужен для первого испытания.
- Router.Cheap: пользователь сообщил, что в Kortix отображаются **49 подключённых моделей**; наличие в списке **не доказывает успешные вызовы**, особенно vision/tool calling. Внутренние ключи/доступ к счётам не сохранять в Git.

- Отдельная линия CAREER-01: все 8 направлений остаются в спецификации, **оперативно утверждены только первые 3**: широкий поиск вакансий → реальное профессиональное русскоязычное портфолио → два достоверных CV. Внешние отклики/публикации только по отдельному разрешению.
- Ночная попытка AWE породила некачественные/отклонённые пользователем шаблоны; не выдавать их за принятый результат.
- Создан самописный `awe-model-council` (GitHub начальный commit `29c91dd`); практика показала неполноценные ответы, обрезание и отказ некоторых моделей; **не делать его базой AWE**.
- Пользователь пробовал Kortix Desktop, подключал Router.Cheap, обсуждал платные кредиты платформы. Стандартный self-host Kortix не устраняет по умолчанию оплату внешних песочниц; потому Kortix **не выбран как основной runtime AWE**, но может использоваться для сравнения возможностей.

- OpenAI Dots обсуждался как возможный менеджер длительной разработки на Pro, но доступ в аккаунте и фактическое исполнение AWE через него **не подтверждены**, подписку покупать пользователь не планирует.

## 5. Кандидаты и совместимость

1. **Agent Zero** — первый кандидат на базовое приложение: интерфейс, локальное выполнение, субагенты, память, инструменты, MCP, расширяемость; оценка реальной эксплуатации на ASUS — НЕ ПРОВЕДЕНА.
2. **Eigent (CAMEL)** — резерв как готовый desktop/Workforce, особенно при проблемах Agent Zero с параллелизмом и мониторингом. Не встраивать целый конкурентный backend без доказанной необходимости.
3. **OpenHands SDK/Agent Server** — подключаемый специализированный coding-исполнитель, только если штатных coding-функций недостаточно.
4. **Microsoft Agent Framework / LangGraph** — не готовые альтернативные UI, а возможные библиотеки для отдельных сложных workflow после тестов; не добавлять преждевременно.
5. **OpenManus / открытые модули Kortix** — опционально, с аудитом лицензий и реальной добавленной стоимости.
6. **Платный Manus AI** — возможный исследователь и инженерный исполнитель, но агентные кредиты расходуются даже при `This PC`; `This PC` не превращает Manus в бесплатное решение. Для предварительной оценки выбран Manus 2.0 Max / Medium, Temporary cloud computer, `Approve for me`, без разрешения начинать разработку.

**Ранее обсуждавшиеся приблизительные оценки соответствия** Agent Zero 76%, Eigent 72%, OpenHands 64%, Kortix 81% — были субъективными оценками, **не тестовой метрикой и не вероятностью успеха**. В новом чате не трактовать их как подтверждённые.

## 6. Главное новое решение владельца и настроение

Владелец сформулировал метафору: **«берём готовую машину, которая уже едет, тормозит и показывает бензин; мы добавляем тюнинг, а не создаём двигатель»**. Это основа всех дальнейших архитектурных решений.

После множества неудачных попыток, расходов и повторяющихся смен платформ пользователь говорит о потере мотивации и сильном разочаровании. **Не нагружать его новыми установками, расходами, длинными экспериментами или обещаниями «на этот раз точно всё заработает».** Дать честную приёмку, доказательства и практический экономный путь. Не считать эмоции разрешением на новую разработку.
