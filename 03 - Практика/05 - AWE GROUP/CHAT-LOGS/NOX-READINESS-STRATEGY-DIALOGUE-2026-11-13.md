## Зафиксированные предложения ассистента (не равны утверждённому плану владельца)

- Непосредственная цель: `владелец → Nox → результат`, без обязательного посредника OpenCode.
- Предварительные P0 gaps: tool discovery-to-execution, Agent Factory scoped grants, Model Router фактические model choices, lifecycle/recovery, QA immutable criteria, прямой интерфейс, доставляемый artifact.
- Предварительный stress-подход: baseline inventory; контрактные тесты отдельных компонентов; интеграционные негативные тесты; chaos/нагрузка 1→3→5 параллельных миссий, 100+ синтетических проверок; затем при авторизованном бюджете 5–10 неизвестных живых задач. Числа предложены ассистентом, не приняты как fixed SLA.
- OpenCode: наблюдение и независимая диагностика, не исправление испытания по ходу и не выдача своих артефактов как Nox-authored.
- Прежде чем стартовать stress, запросить собственное критическое read-only заключение OpenCode. Полный скрипт находится в `PROMPTS/NOX-OWNER-READINESS-REVIEW-01-2026-11-13.md`. **Не отправлялся**, пользователь отдельно не одобрял запуск stress.
- Предыдущая инженерная веха: Nox создал локальный NIVICT сайт через AWE, независимый QA 13/14 (FAIL по README), owner дизайн-оценка 2/10; раздельные оси качества.
- Параллельная аналитика LLM провайдеров: оставить Router.Cheap некритичным, OpenRouter резерв после пилота, прямые OpenAI/Anthropic как disaster fallback; отдельно загруженный полный отчёт сохранён в RESEARCH.
