# AWE GROUP — журнал переписки (CHAT-LOGS)

**Начало:** 2026-11-10. **Репозиторий:** `failm3/nivict-ai-academy` (`public` на момент настройки).

## Владелец потребовал
Записывать **каждое** новое сообщение пользователя и ассистента (дословно, отдельно), сохранять исходные /goal-промпты, файлы, технические выводы, решения, ошибки и контрольные точки, чтобы новый чат мог восстановить всё без догадок. Владелец 2026-11-10 явно согласился на публикацию переписки в открытом репозитории и признал риск конфиденциальности. Пароли, действующие API-ключи, токены и иные аутентификационные секреты не публиковать; помечать факт редактирования. Публичная Git-история может сохранять данные после удаления файлов.

## Организация
- `YYYY-MM-DD/NNNN-user.md` — дословное входящее сообщение (по возможности вместе с ссылкой на приложение; приложение не считается заархивированным до отдельной проверки байтов).
- `YYYY-MM-DD/NNNN-assistant.md` — дословный текст соответствующего ответа; не заменять итоговой сводкой.
- `YYYY-MM-DD/STATE.md` — проверенная оперативная контрольная точка; этот документ **не** заменяет журнал.
- Не перезаписывать ранее сохранённые сообщения; исправления и пропуски оформлять новой записью. Проверять `commit_sha` и чтение файла обратно из GitHub.
- При восстановлении: читать журнал в хронологии, оригинальные промпты и последний STATE, затем сравнивать с работающей системой.

## Реальное состояние автоматизации
**AUTO_INGEST = NOT_IMPLEMENTED.** Создание GitHub-папки и запись сообщений через доступный коннектор происходят только при вызове инструмента ассистентом. У ChatGPT в этом разговоре нет постоянно исполняющегося фонового обработчика и автоматического потока всех сообщений из приложения во внешний webhook. Поэтому никакой гарантии «каждое сообщение во всех чатах записывается автоматически» сейчас нет.

Для гарантии нужен реально развернутый и проверенный collector из клиента/интеграции, имеющей доступ к событиям сообщения: capture (user + assistant + attachments) → local durable queue → secret scrub → append-only write → Git commit → readback → retry / gap detection / alert. Без event source только GitHub Actions или cron не видят чат ChatGPT. **Не утверждать, что автоматизация готова, пока сквозной тест этого контура не пройден.**

## Начальные ограничения
Сообщения до создания данного журнала не объявляются автоматически восстановленными. Текущие записи от 10 ноября — только явно зафиксированные сообщения/контрольная точка. Все пропуски должны быть видимы. Более старые сводки и переписки могут содержаться в других местах; ссылаться на них с проверкой.
