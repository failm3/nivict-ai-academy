## Честные ограничения сохранения
- Ранние пользовательские реплики хранятся в `0001-user.md`…`0041-user.md`, некоторые ID имеют исторические пробелы. В этой передаче новые 15 файлов созданы и проверены; это **не доказательство**, что абсолютно все сообщения всей истории из всех чатов когда-либо экспортированы.
- Текущая интеграция GitHub не предоставляет полный платформенный ChatGPT conversation dump, поэтому нет гарантии посимвольной копии всех assistant UI ответов. Их содержательная последовательность и исходные технические промпты сохранены.
- Ни автоматическая архивация каждого нового сообщения в GitHub, ни автоматическое восстановление всех приватных вложений между чатами пока не доказаны.
- Источники секретов и raw Recorder логи не следует пересылать в будущие чаты без редактирования.
