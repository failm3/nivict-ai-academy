## Рабочие решения, не потерять

- Пользователь предпочитает диалог по-русски, простые понятные аналогии «ребёнок», «стажёр», «мастерская», но технические факты должны быть строгими; коротко и по делу, без декоративных похвал.
- Обязательное требование GitHub readback для важных сообщений/решений. Recorder OpenCode — НЕ автоматический лог сообщений текущего ChatGPT; фиксацию этой беседы мы выполнили отдельно.
- Идея Unslop → domain capability pack сохранена как необязательная для R0, дальнейшее обсуждение после текущих результатов.
- Нельзя смешивать «Nox сам создаёт подагентов» и «OpenCode сам создаёт LLM-помощников для инженерной работы».
- Нельзя принимать повторные красивый отчёт и nominal PASS без проверки actual mission/tool traces.
- Системная готовность и технический QA ≠ оценка дизайна владельцем.
- Нельзя объявлять R0 завершённым или R1 разрешённым без фактических тестов и решения владельца.
- Нельзя обещать автоматическое фоновое сохранение будущих сообщений, если такой workflow реально не настроен.
