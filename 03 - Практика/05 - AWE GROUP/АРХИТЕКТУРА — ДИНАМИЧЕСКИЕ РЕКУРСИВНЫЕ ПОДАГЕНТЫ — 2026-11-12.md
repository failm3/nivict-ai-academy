# AWE GROUP: рекурсивное делегирование и создание агентов на лету

## Ключевое уточнение требования владельца

**Не нужно предварительно создавать штат исполнителей.** Главный агент должен принимать неизвестную миссию, создавать под неё специализированного агента-руководителя; тот по необходимости порождает дочерних агентов, которые могут делегировать дальше. Head контролирует верхнеуровневую миссию, передаёт/получает компактный контекст и результаты, не выполняет мелкие задачи сам. Каждому работнику — отдельный контекст, модель, инструменты, полномочия, отчёт, жизненный цикл.

Число задач заранее не ограничивать фиксированным перечнем; в runtime обязательно ограничивать **одновременно активных исполнителей, глубину рекурсии, бюджеты, шаги и повторные вызовы**. Не путать гибкость задач с бесконечными вычислительными ресурсами.

## Проверенные существующие примитивы Agent Zero

- `tools/call_subordinate.py`: `get_or_create_subordinate(parent, profile, reset, context_id, name, message, slot)` создаёт Agent с `parent.number+1`, отдельным context, parent-context linking и возможностью продолжения. Документация сообщает о multi-agent cooperation.
- По опубликованному changelog Agent Zero: recursive rendering подчинённых, nested task ownership, unified parallel calls; фактическое исполнение на компьютере владельца **не проверялось**.
- Встроенный Skill `skills/a0-create-agent/SKILL.md` описывает создание профиля и последующее делегирование через `call_subordinate`.
- Ссылки на код:
  - https://github.com/agent0ai/agent-zero/blob/main/tools/call_subordinate.py
  - https://github.com/agent0ai/agent-zero/blob/main/skills/a0-create-agent/SKILL.md
  - https://github.com/agent0ai/agent-zero/releases
- Следует отдельно проверить: агент может ли в ходе миссии **сам создать/выбрать новый профиль** и делегировать ему работу; действительно ли вложенные и параллельные подагенты выполняются, возвращают корректные артефакты; автономно ли выбираются модели и права.

## Новая идея владельца: Telegram-источники

Владелец предлагает предоставить Manus **две Telegram-ссылки на каналы/материалы с агентами и инструментами**, чтобы он нашёл уже существующие решения. **Сами две ссылки в текущем обращении не переданы**; не выдумывать адреса или результаты. Открытые каналы можно изучать как кандидатов, приватные — только при предоставленном правомерном доступе/экспорте. Публикации Telegram — не доказательство совместимости, репутации или безопасности.

Рекомендовать прежде всего направленный отбор по задаче (динамические профили, рекурсивные подагенты, управление инструментами, Skills, MCP, QA), с фиксацией оригинальных repo, лицензий, требований, дат обновления, рисков. Не начинать платные исследования/установки/разработку без новой явной команды.

## Решение этого обсуждения

Цель полностью реализуема архитектурно; базовый механизм создания/иерархии подагентов **существует** в open-source Agent Zero. Это не является доказательством полноценной автономной AWE. Следующий шаг, после разрешения, должен быть **практическим тестом рекурсивной генерации агентов**, а не написанием альтернативного оркестратора.

**Не изменять исходный `/goal`, CAREER-01, действующую локальную AWE, ключи, лимиты или рабочие процессы.**
