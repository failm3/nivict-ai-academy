# Прикладные возможности Nox: фактический scope

Статусы описывают source wiring и сохранённые evidence, не свежий runtime acceptance.

| Capability | Фактическое состояние | Главный пробел / следующий проверяемый шаг |
|---|---|---|
| Specification/approval | Wired; typed spec, hash binding, explicit approval | Clarification/edit loop и objective domain oracle до approval |
| Orchestration | Wired; Head, parallel batches, recursive specialists, checkpoints, repair | Ранняя outcome baseline; no silent generic planning fallback |
| Software engineering | Generic files/shell/build/test; наиболее близкая практическая capability | Mission workspace не provisioned repo; host `.git` скрыт; нет clone/worktree/PR/change-impact pack. Slice: independently applied patch + tests |
| Local artifacts | Strong integrity/recovery, реальные bytes/hash/size | P0 nested path/revision и immutable reviewed candidate |
| Research | Search/fetch/extract и generic researcher | Source/claim ledger, edition/rights/ACL, stable anchors, contradiction/retraction и citation completeness |
| Browser | Пять MCP wrappers; отдельный direct Playwright web verifier имеет historical live evidence | Unpinned package, schema mismatch, singleton, containment/egress/cleanup; production MCP live path NOT_PROVEN |
| Web product | Независимый verifier реального static Task tracker; exact tree 13/13 historical PASS | Не SSR/backend/API/auth/CMS/full-stack; нет общей visual/accessibility qualification |
| UI/UX/design/images | Text designer specs; screenshots возможны как bytes | Нет image generation в доступном Router.Cheap tool catalog на момент audit; QA получает image path, не pixels. Нужен visual oracle и typed artifacts |
| Analytics | Exact integer-cent CSV solver + independent recomputation | Жёсткая schema USD/EUR sale/refund; не general analytics. Добавить один XLSX/gold case после P0 |
| Documents | Generic text/Markdown artifacts | Нет production PDF/DOCX/XLSX/PPTX/OCR/table/reading-order/native rendering pipeline; Markdown не эквивалент DOCX/PDF |
| Marketing/content | Generic researcher/writer/web | Нет brand/channel typed contracts, campaign/CRM connectors, publication controls и domain oracle |
| Automation/workflows | Можно производить scripts через shell | Нет trigger/scheduler/event queue/idempotent workflow runtime; выбирать route по задаче |
| External APIs/deployment | Generic web fetch/shell; deny/unknown-effect controls полезны | Нет host-held credential broker, operation-key reconciliation, environments/rollout/rollback; external effects отдельно approve |
| MCP/tool discovery | Один Playwright client + read-only research catalogs | Нет dynamic granted ToolSearch и approved registry/admission/revocation lifecycle |
| Skills/plugins | Dynamic role prompts и узкий CSV lesson, не Skill platform | Нет immutable manifests, installer/activation/ACL/revoke/held-out qualification |
| Memory/learning | LibSQL history; semantic/working recall off; scoped lesson reuse | Нет cross-mission retrieval/ACL; measured learning delta 0 в сохранённом fixture; не строить RAG без use case |
| Models/economics | Role defaults и trusted host byAgent/byRole; durable SDK ledger | Нет adaptive quality/cost routing; whole-mission tokens и USD неполны/UNKNOWN |
| API/observability | Authenticated CLI/REST, logs/artifacts/tree/checkpoints | Нет artifact download/preview, mission event stream, usage endpoint и human review console |
| Windows computer-use | Absent | Отдельный Windows VM/broker/UI Automation + visual/accessibility oracle; browser/Linux evidence не засчитывать |
| Multi-tenancy | Single shared-secret trusted-host model | До shared exposure требуется tenant identity/partitioning всех state/evidence surfaces |

## Рекомендуемый порядок профессиональных slices

1. Repository patch — ближайший к текущему коду и проверяет полезный engineering loop.
2. PDF/DOCX ingestion и native output — наибольший новый прикладной разрыв.
3. Dynamic browser с DOM + visual verification — после MCP security repair.
4. Один новый analytics format — с независимым recomputation.
5. Один draft-only API effect — secret broker, idempotency key, timeout-after-commit reconciliation.

Каждый slice получает named scope, immutable inputs, independent oracle, negative controls, recovery и full usage record. Успех одного slice не распространяется на всю профессию.
