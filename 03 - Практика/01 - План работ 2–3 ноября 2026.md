# План работ — 2–3 ноября 2026

> Оперативный план. **Плановые задачи не являются выполненными.** Приоритет — артефакты к двум созвонам 3 ноября и поиск работы, а не формальный счётчик завершённых уроков.

## Итоговое решение

- Учебную программу **не изменять**. Сейчас [[02 - Курс/07 - Прогресс|F03 из 18]], F01–F02 пройдены на вводном уровне. Быстрый курс F03–F18 по возможности просмотреть 2 ноября; непонятные темы помечать для повторения, не выдавать за освоенные.
- **Главный практический продукт** — [[03 - Практика/00 - NIVICT Agent System — стратегия и требования|NIVICT Agent System]], развитие существующего Workspace, а не создание дубликата с нуля.
- **Второй крупный поток** — новый коммерческий сайт: сначала продуктовая концепция и сценарии, потом детальный дизайн.
- **Третий поток** — подготовка одного сотрудника к разработке агентов.
- **Четвёртый поток** — портфолио и HeadHunter: критично для трудоустройства; основная работа 3 ноября после созвонов.
- **Пятый, долгосрочный поток** — NIVICT AI Lab, исследовательская собственная LLM; сейчас не отвлекает от срочных задач.

## Понедельник, 2 ноября — что подготовить

### A. Быстрый вводный курс — ориентир 2–2,5 часа

- [ ] В ускоренном режиме разбирать F03–F18 по утверждённому маршруту, по одной идее за раз.
- [ ] Сохранять честные статусы освоения и качественные конспекты, а не стенограммы.
- [ ] При нехватке времени сокращать теорию; рабочие материалы к завтрашним встречам важнее числа «закрытых» уроков.

### B. Новый сайт — ориентир 3 часа (к созвону 3 ноября)

- [ ] Уточнить целевую аудиторию, проблему, ценность и ограничения проекта.
- [ ] Сформулировать предложение продукта и границы первой версии.
- [ ] Набросать карту сайта и основные пользовательские пути.
- [ ] Составить схематичные ключевые экраны / структуру блоков, не начинать с декоративной полировки.
- [ ] Список решений, на которые необходимо получить ответ на созвоне.

**Ожидаемый результат:** компактная продуктовая концепция, структура и сценарии сайта, черновые схемы, вопросы. **Тематика нового сайта пока не зафиксирована в этом документе**; не подставлять другой проект автоматически.

### C. Агенты и подготовка сотрудника — ориентир 2–2,5 часа (к созвону 3 ноября)

- [ ] Подготовить короткий маршрут сотрудника: bot / workflow / LLM / agent / tools / orchestration / memory / testing.
- [ ] Подготовить простое первое практическое задание сотруднику и критерии приёмки.
- [ ] Получить и проверить актуальные исходники и конфигурацию NIVICT Workspace.
- [ ] Составить независимую техническую картину: что реально работает, что лишь заявлено, какие риски/неисправности.
- [ ] Выбрать первоочередной практический сценарий главного агента: карьерная помощь и портфолио / управление проектами / создание первого специализированного агента.
- [ ] Не затевать полный рефакторинг вместо подготовки ко встречам.

**Ожидаемый результат:** план вводного обучения сотрудника, предварительный подтверждённый технический статус Workspace и ближайшая проверяемая инженерная задача.

### D. Проверка и резерв — ориентир 45–60 минут

- [ ] Подготовить две повестки созвонов.
- [ ] Сложить материалы так, чтобы их можно было открыть и показать.
- [ ] Отделить выполненное от запланированного; обозначить незакрытые вопросы и ответственных.
- [ ] Заложить время на непредвиденные проблемы.

## Вторник, 3 ноября — встречи и трудоустройство

### Встреча 1. Обучение сотрудника и внедрение агентов

**Цель:** согласовать, чему учить, как организовать участие сотрудника в разработке и какую первую проверяемую задачу ему дать.

Ожидаемое решение: роли, зона ответственности, доступы, учебный формат и критерии результата.

### Встреча 2. Новый коммерческий сайт

**Цель:** согласовать продуктовый принцип и содержание первой версии, чтобы проект мог стартовать на неделе с 9 ноября.

Ожидаемое решение: аудитория, ключевая ценность, обязательные сценарии, структура, границы MVP, ответственные и следующий этап дизайна.

### После встреч: портфолио и HeadHunter

- [ ] Аудит [[03 - Практика/00 - NIVICT Agent System — стратегия и требования|задач портфолио]] и действующего сайта `https://nivict.ru/design`.
- [ ] Выделить сильнейшие реальные кейсы: Яндекс, СБОРКА, КиберЩит, Money Flow, NIVICT; перечень требует проверки по фактическим материалам.
- [ ] Улучшить роль, формулировку проблемы, ход работы, визуальные доказательства и *измеренные*, а не придуманные результаты.
- [ ] Проверить читаемость кейсов и корректную работу сайта на разных экранах.
- [ ] Подготовить резюме для роли «продуктовый дизайнер»; продуктовый маркетинг — дополнительный трек, не размывающий основной профиль.
- [ ] Проанализировать релевантные вакансии HH, подготовить адаптацию резюме и первую волну качественных откликов.
- [ ] Отделить «готово к откликам» от желательной, но не критической дизайн-полировки.

## Приоритет при нехватке времени

1. Материалы к обоим созвонам **должны быть готовы до встреч**.
2. Портфолио и резюме — ближайший источник карьерного результата, нельзя откладывать без конца.
3. Минимальная работающая автоматизация важнее масштабного переписывания агента.
4. Быстрый курс допускает перенос непройденных блоков; **никаких ложных статусов completed**.
5. Собственная LLM — отдельная исследовательская работа, только после покрытия срочных задач.
